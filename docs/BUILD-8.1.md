# Build 8.1 — Mindset Repair Explanations

Build 8.1 improves Mixed Practice without adding a new learning mode.

When the learner misses a CISM mindset dimension, feedback now explains briefly:
- what they selected
- what the correct mindset signal was
- why that signal fits the question
- a compact Memory Rule

Covered mindset dimensions:
- Qualifier
- Role / authority
- Lifecycle
- Decision context

Calm-UI rule:
- Correct mindset dimensions remain compact.
- Only missed dimensions receive the additional explanation.
- If all four are recognized, the learner gets one quiet confirmation rather than four explanations.

Purpose:
Repair the reasoning model, not just mark a label incorrect.
