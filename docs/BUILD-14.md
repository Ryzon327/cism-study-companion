# Guided Daily Study Coaching

This release makes Daily Study the primary learning path rather than requiring the learner to choose among many tools.

## Changes
- Removed learner-facing build/version labels.
- Simplified primary navigation to Study and Progress; Explore and Practice engines remain available to Daily Study and existing internal flows.
- Daily Study now follows: Quick Recall → Definitions → Lifecycle Application → CISM Question Decoder → Exam-style Application → Today's Signals → Complete.
- Added exam-useful definitions with plain-English meaning, recognition clues, common distinctions, and memory rules.
- Added interactive lifecycle scenarios so learners practice identifying the current stage and why tempting actions are premature.
- Added explicit question-decoder teaching for role, qualifier, lifecycle, decision context, and constraints before exam-style application.
- Correct answers now receive explanations too, including why the answer matters and how to recognize the pattern.
- Added calm Current Focus language based on evidence rather than negative grading language.
- Completion recommends the next action, with “come back tomorrow” as the default and only a small optional reinforcement when useful.
- Target session length is approximately 25–35 minutes without a forced timer.
