# Build 9 — Practice Exam + Exam Readiness

Build 9 adds the first true no-coaching exam mode.

## Practice Exam
- Mixed questions across all four CISM domains
- No domain labels during the exam
- No qualifier/role/lifecycle prompts
- No Memory Rules during the exam
- No correctness feedback until submission
- Previous/Next navigation
- Mark-for-review
- Unanswered-question warning before submission

## Readiness
After submission:
- raw practice score
- domain-weighted readiness score
- per-domain performance
- missed-concept repair list
- detailed review of missed questions
- Memory Rules return only after submission
- exam misses feed the same adaptive mastery/repair engine
- readiness history stored locally
- recent-session readiness average shown in Progress

## Important interpretation
The readiness percentage is an internal study signal. It is not an ISACA scaled-score prediction and does not claim that a particular percentage guarantees a passing exam result.

## Scope discipline
Build 9 does not add another learning mode. It tests whether the existing Study → Active Practice → Mixed Practice system transfers to an exam-like environment.
