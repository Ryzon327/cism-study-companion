# Build 7 — Memory Rules in Study

Build 7 brings the compact Memory Rule reinforcement used in Active Practice directly into Study mode.

Implemented:
- Memory Rule inside each Foundation Study step
- Memory Rule repeated after question feedback
- Study home Memory Rules panel
- Study home rules adapt to Learning / Needs Refresh concepts from Active Practice
- Active-practice misses therefore surface their compact anchors back in Study
- fallback core CISM rules appear before enough performance evidence exists

Design principle:
Memory Rules compress an already taught concept. They reinforce understanding; they do not replace lessons, comparisons, scenarios, or repair.
