# Build 2 — Study Engine

Build 2 turns the visual shell into a functioning learning flow.

Implemented:
- resumable study session
- Recall → Learn → Compare → Pattern → Guided → Independent → Close
- CISM Question Decoder
- confidence capture
- answer locking and feedback
- targeted repair explanations
- transfer scenarios after misses
- question-attempt history in browser storage
- JSON backup includes attempts
- source-grounded Foundation lesson using Domain 1 patterns

This build intentionally uses a small set of Domain 1-supported concepts so the engine can be validated before Build 3 scales the curriculum.
