# Build 15 — Curriculum Progression & Taught-First Adaptation

Build 15 fixes the mismatch between the visible Journey and Daily Study.

## Curriculum
Foundation → Domain 1 → Domain 2 → Domain 3 → Domain 4 → Adaptive Reinforcement.

During first-pass learning:
- the current curriculum domain controls Daily Study
- future-domain performance data cannot jump the learner ahead
- Recall can use only introduced material plus core CISM reasoning anchors
- Daily Study application questions are filtered to the current or already introduced concepts
- the app does not label untaught future-domain material as a weakness

A domain advances after the planned concept set has been introduced through Daily Study. Advancement occurs when the current session closes.

After all four domains are completed:
- Daily Study enters Adaptive Reinforcement
- it may choose the domain based on practice/exam evidence

## Journey UI
The Journey now derives from curriculum state and shows Completed / Current / Upcoming.
The prior lifecycle preview is now the CISM Big Picture rather than a fake progress tracker.

## Quantitative risk
Domain 2 now adds supplemental foundational teaching and practice for:
AV, EF, SLE, ARO, ALE
SLE = AV × EF
ALE = SLE × ARO
and management/cost-benefit interpretation.

The user's supplied practice material supports quantitative risk concepts, asset valuation, ALE, and cost-benefit reasoning; the exact formula drills are supplemental foundational teaching.

## Preserved
Question wording variance, answer-position variance, Mixed Practice, confidence, Practice Exam review navigation, Recall, and post-answer explanations are preserved.
