# Build 10 — Scenario & Pattern Question Engine

Build 10 expands question depth without adding another learning mode.

- 36 source-grounded pattern families across all four domains
- 72 scenario variants for recurring CISM mental models
- prior mixed/exam questions remain in the pool
- family-diversity-first exam selection
- recent question and family de-prioritization
- answer-position shuffling every exam
- question/family history saved with exam results
- same 40-question weighted exam format

Goal: memorizing wording or answer letters should be insufficient. Learners must recognize the underlying CISM decision pattern.

Scope boundary: this is the final question-engine architecture. Future additions should address genuine source-coverage gaps rather than add endless question modes.
