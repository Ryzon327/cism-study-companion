# Build 4 — Active Learning & Retention Engine

Build 4 converts the Build 3 knowledge catalogue into active learning.

Implemented:
- Active Practice inside each domain
- four reusable learning interactions:
  - Distinguish
  - Sequence
  - Apply
  - Pattern recognition
- source-grounded scenario practice across Domains 1–4
- lifecycle sequencing challenges
- immediate reasoning feedback and compact memory rules
- active-learning result storage
- per-concept mastery evidence
- per-domain active-retention evidence
- active-learning data included in backup/export
- Progress screen shows retrieval evidence rather than rereading activity

Design principle:
The app should confirm understanding through retrieval, discrimination, sequencing, and transfer — not by repeatedly showing definitions.

This does not replace the Build 2 daily Study Engine. Active-learning interactions are reusable components that can be pulled into future daily sessions and retention review.
