# Build 11 — Daily Study Orchestrator

Build 11 connects the learning engines already built into one calm daily study path.

## Daily flow
1. Recall (~5 min)
   - Retrieve compact Memory Rules before revealing them.
   - Weak / Needs Refresh concepts receive priority.

2. Focused Review (~7 min)
   - One targeted concept only.
   - Plain-English explanation + CISM lens + Memory Rule.
   - No requirement to browse the full domain.

3. Apply (~10 min)
   - Launches the existing domain Adaptive Practice for the selected focus domain.
   - Results continue to feed the shared mastery/repair engine.

4. Mixed CISM (~8–10 min)
   - Launches the existing Mixed Practice engine.
   - Confirms transfer without domain labels.

5. Close (~2 min)
   - One compact anchor.
   - Summarizes today's focus.
   - Explicitly ends the session without creating backlog pressure.

## Adaptive focus
Today's focus is selected from:
- weakest domain on the latest Practice Exam, when available
- Learning / Needs Refresh concepts
- domain active-practice evidence
- Domain 1 as the clean starting point when no evidence exists

## Principles
- no forced schedule
- no streak
- no overdue backlog
- no requirement to manually decide what to review
- no daily practice exam
- existing Study, Explore, Active Practice, Mixed Practice, and Practice Exam remain available independently

Purpose:
Turn the application from a collection of strong study tools into a coherent day-to-day CISM study experience.
